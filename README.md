# tandem — sitio web

Sitio estático de una sola página: `index.html` + `favicon.svg`. No necesita build.

- Color de acento: `#2F5BFF` (buscar y reemplazar para cambiarlo).
- Fuentes desde Google Fonts: Instrument Serif (diseño), Space Grotesk (tecnología), Inter (texto) y JetBrains Mono (etiquetas).
- Todos los botones abren WhatsApp con un mensaje ya escrito (`https://wa.me/50362613212?text=...`); el número no se muestra en la página.

Publicación: conectar este repositorio a Cloudflare Pages o Netlify, sin comando de build y con la raíz `/` como carpeta de salida.
